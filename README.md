# Граф прав

MVP модуля преобразования реляционной модели данных видеохостинга в графовую для выявления взаимосвязей объектов, связанных с нарушениями авторских прав.

Модуль переносит таблицы видеохостинга (пользователи, видео, произведения, правообладатели, лицензии, жалобы, блокировки, совпадения с защищённым контентом, связи аккаунтов) в граф и ищет подозрительные цепочки. Пример: видео содержит защищённое произведение, лицензии у загрузившего нет, на видео уже поступали жалобы. Для каждой цепочки считается риск от 0 до 100%.

Модуль выявляет признаки и связи для дальнейшей проверки. Юридически факт нарушения он не устанавливает.

## Возможности

1. **Загрузка данных:** демо-набор, CSV-файлы или подключение к PostgreSQL (в браузерной версии эмулируется). Таблицы можно вручную сопоставить с объектами графа, а поля — со столбцами. Обязательные поля проверяются.
2. **Схема преобразования** в двух видах — карточками или таблицей. Редактор связок: таблица-источник, роль, название вершины, ключ, подпись, связи из внешних ключей, свойства. Обязательные настройки заблокированы.
3. **Поиск подозрительных цепочек** с оценкой риска и шестью аналитическими запросами (Cypher). Изменения в исходных данных пересчитывают граф и риск.
4. **Разбор цепочки на интерактивном графе:** карточки вершин и рёбер, добавление и удаление соседей, несколько раскладок. Решение: «нарушение», «не нарушение» или «нужна проверка юристом».
5. **Обзор крупного графа:** порог риска, распределение, история изменений риска, разбиение на подграфы.
6. **Аналитики:** поиск по ФИО, список проверивших, журнал работы.
7. **Отчёт** с выгрузкой в CSV и PDF.

## Запуск

Сборка не нужна: всё приложение — один файл `index.html`.

- **Локально:** откройте `index.html` в браузере.
- **GitHub Pages:**
  1. Загрузите файлы в репозиторий.
  2. Откройте **Settings → Pages**.
  3. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`.
  4. Через минуту сайт будет доступен по адресу `https://<имя-пользователя>.github.io/<репозиторий>/`.

Нужен доступ в интернет: библиотека графов Cytoscape.js загружается с cdnjs, шрифты — с Google Fonts.
